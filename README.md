COVID-19 Detection App

This project is a COVID-19 Detection Web Application developed using Python, Streamlit, and Deep Learning techniques. The application analyzes chest X-ray images and predicts whether a patient is COVID-19 positive or negative.


Multiple deep learning approaches were implemented and compared:-
1. Basic CNN Model
2. Transfer Learning using VGG16
3. Data Augmentation + VGG16

The best-performing model was selected and integrated into the Streamlit application for real-time predictions.

Features:-
1. Upload Chest X-ray images for prediction
2. User-friendly Streamlit web interface
3. Fast and accurate COVID-19 detection

Application Workflow:-
1. Upload a chest X-ray image.
2. The image is preprocessed.
3. The trained deep learning model analyzes the image.
4. The application displays the prediction:
5 .COVID-19:- Positive/Negative

Technologies Used:-
1. Python
2. TensorFlow 
3. Streamlit
4. NumPy
5. Pandas
5. Matplotlib
6. OpenCV
7. Scikit-learn
